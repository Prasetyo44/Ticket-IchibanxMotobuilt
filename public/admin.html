Karyawan mendapat maksimal 2 tiket. Kalau butuh lebih, mereka mengajukan lewat halaman tiket. Setujui untuk mengambil QR dari stok dan menambahkannya ke halaman tiket mereka. Pastikan stok QR cukup.

Stok tiket QR dari IMOS

Upload semua file tiket dari IMOS (PNG, JPG, WebP, atau PDF) — satu file = satu tiket. Saat karyawan mendaftar, sistem mengambil 1–2 file dari stok dan menampilkan file aslinya (tanpa diubah) hanya di halaman tiket website. Kalau pendaftaran dibatalkan, file kembali ke stok dan bisa dipakai karyawan lain. File dengan isi yang sama tidak akan masuk dua kali.
